# Forge-OS

Forge-OS is a full-stack MERN (MongoDB, Express.js, React, Node.js) application built with TypeScript, designed to deliver a modular digital workspace experience.

🌐 **Live Demo:** [forge-os-three.vercel.app](https://forge-os-three.vercel.app)

---

## 🚀 Tech Stack

*   **Frontend:** React, TypeScript, Vite
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB
*   **Deployment:** Vercel
